## ✍️ AI 写作

### 新媒体内容

#### 小红书爆款笔记

```
你是一位小红书爆款写手，请帮我写一篇关于[主题]的笔记。
要求：
1. 标题：包含emoji，吸引眼球，字数控制在20字以内
2. 开头：第一句就要抓住人，制造共鸣或好奇心
3. 正文：
   - 分点清晰，用emoji做序号
   - 口语化表达，像和闺蜜聊天
   - 加入个人体验和真实感受
   - 适当使用网络热词
4. 标签：5-8个相关话题标签
5. 字数：300-500字

风格参考：[干货分享/日常vlog/好物推荐/避坑指南]
```

#### 抖音/快手脚本

```
请帮我写一个[时长]秒的抖音短视频脚本。
主题：[视频主题]
人设：[描述博主人设]
目标受众：[受众描述]

请输出以下内容：
1. 【标题】吸引点击的标题（含悬念/反差/利益点）
2. 【分镜脚本】
   - 0-3秒：黄金开头（必须留人）
   - 3-XX秒：主体内容
   - 最后3秒：互动引导/结尾彩蛋
3. 【字幕文案】逐字稿
4. 【BGM建议】
5. 【话题标签】5个
```

#### 公众号深度长文

```
请以[主题]为核心，撰写一篇微信公众号深度文章。
文章类型：[干货教程/观点评论/人物故事/行业分析]
目标读者：[描述你的读者画像]
预期字数：2000-3000字

结构要求：
1. 【开头】（3种可选风格任选其一并说明理由）
   - 故事引入法
   - 痛点提问法
   - 反常识观点法
2. 【主体】分3-5个小节，每节包含：
   - 核心观点
   - 案例/数据支撑
   - 行动指导
3. 【结尾】总结升华 + 金句 + 互动引导
4. 【封面图描述】给设计师的需求

语言风格：[专业严谨/轻松幽默/温暖治愈/犀利尖锐]
```

### 商业写作

#### 商业计划书

```
请帮我撰写一份商业计划书的框架和核心内容。
项目名称：[项目名称]
项目简介：[一句话描述]
商业模式：[描述盈利模式]
目标市场：[目标用户和市场规模]

请按以下结构输出：
1. 执行摘要（200字以内，提炼核心亮点）
2. 市场分析（痛点、市场规模、竞争格局）
3. 产品服务（核心功能、差异化优势）
4. 商业模式（收入来源、成本结构）
5. 运营策略（获客方式、增长路径）
6. 团队介绍（核心成员亮点）
7. 财务预测（3年关键指标）
8. 融资需求（金额、用途、退出方式）
```

#### 销售话术/文案

```
你是一位金牌销售，请帮我撰写一套针对[产品/服务]的销售话术。
产品信息：[描述产品核心功能和优势]
目标客户：[客户画像]
客户痛点：[列出3-5个核心痛点]
竞品情况：[简述竞品情况]

请输出：
1. 【开场白】3种不同风格的开场（寒暄式/问题式/价值式）
2. 【需求挖掘】5个关键提问，层层递进挖掘客户需求
3. 【产品介绍】FABE法则（特征-优势-利益-证据）
4. 【异议处理】5个常见反对意见及应对话术
5. 【促单成交】3种逼单技巧
```

## 💡 提示词使用技巧

### 万能公式

```
角色设定 + 背景信息 + 任务目标 + 输出要求 + 示例参考
```

### 提升效果的 5 个技巧

1. **给 AI 设定角色** — 让 AI 扮演专家角色，输出更专业
2. **提供背景信息** — 上下文越丰富，结果越精准
3. **明确输出格式** — 指定表格/列表/代码/Markdown 等格式
4. **给出示例参考** — 提供1-2个期望输出的样例
5. **迭代优化** — 第一版不满意？让 AI 按你的反馈继续修改

### 常见问题排查

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 回答太笼统 | 提示词不够具体 | 增加更多约束条件和细节 |
| 结果不符合预期 | 理解偏差 | 提供示例，或分步引导 |
| 内容太长/太短 | 没有长度限制 | 明确指定字数/条数/页数 |
| 格式混乱 | 没有格式要求 | 指定输出格式（表格/列表/分点） |
| 事实错误 | 幻觉问题 | 要求 AI 给出数据来源，或交叉验证 |
